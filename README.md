# Text to Speech Converter

A modern web application that extracts text from documents and converts it to speech using advanced TTS capabilities.

## Features

- **Document Extraction**: Upload documents and extract text seamlessly.
- **Text to Speech**: High-quality voice synthesis.
- **Modern UI**: Clean and responsive interface using Tailwind CSS and Next.js.
- **PWA Support**: Progressive Web App capabilities included.

## Tech Stack

- [Next.js](https://nextjs.org/)
- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- TypeScript

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

## Production Build

To create a production build:

```bash
npm run build
npm start
```
